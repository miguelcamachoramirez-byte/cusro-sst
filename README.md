# cusro-sst

Curso interactivo. Proyecto web (HTML, CSS y jQuery) con navegación por pantallas,
transiciones tipo parallax, sonidos y contenido tipo e-learning.

## Cómo ejecutar

El proyecto es estático. Puedes abrir `index.html` directamente en el navegador,
o servirlo con un servidor local para que carguen bien las rutas absolutas:

```bash
# con npx (Node)
npx serve .

# o con Python
python -m http.server 8000
```

Luego abre `http://localhost:8000` (o el puerto que indique la herramienta).

## Dependencias

```bash
npm install
```
